# Notes on project images

- `proposed_system_architecture.png`: planned architecture only. The displayed Rigol DP832A, DUT UART/BLE workflow, OTAU, BLE testing, power analysis, and log analysis are not represented as completed implementation results.
- `implemented_wiring_reference.png`: wiring illustration for the BME280 and LED circuit that was physically implemented. The drawing labels a Raspberry Pi Model 2, while the actual project controller was a Raspberry Pi 4 Model B. Treat the drawing as a wiring reference, not as proof of the controller model.
